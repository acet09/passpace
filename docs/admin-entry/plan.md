# 달력 선택 문구 · 관리자 웹 진입

사용자 요청: 달력의 선택 글자를 없애고 파란 강조를 유지한다. 관리자 계정으로 로그인하면 내 정보에서 관리자 페이지에 들어갈 수 있게 한다.

## 방식과 범위
- 달력의 시각적인 선택 글자만 제거한다. 배정·오늘·빈 날짜 표시, 파란 강조와 접근성 selected 상태는 유지한다.
- 기존 서버는 JWT role=ADMIN을 발급하고 웹 /admin/collect 및 관리자 API를 제공한다. 웹과 같은 role 표시 기준을 사용하되 실제 권한 검사는 그대로 서버가 수행한다. 아이디·닉네임으로 권한을 추정하지 않는다.
- 내 정보에 관리자에게만 관리자 페이지 메뉴를 표시한다. 현재 앱 서버의 /admin/collect를 브라우저로 연다. 웹 로그인은 브라우저가 기존 방식으로 처리하며 앱 토큰·비밀번호는 URL이나 브라우저로 전달하지 않는다.
- 앱에 브라우저 열기 기능이 없어 Android MainActivity의 화면 연결 한 곳을 추가한다. 새 패키지·설정·권한·버전·API·모델·세션·보안 저장소는 변경하지 않는다. 이 Kotlin 파일은 앱 화면 연결 코드이며 팀 백엔드는 읽기 전용이다.
- 변경: lib/ui/auth.dart, plan_month_calendar.dart, 새 admin_link.dart; 앱 Android MainActivity.kt; 관련 테스트·문서·APK. 다른 팀원 코드나 TODO는 수정하지 않는다.

- [x] 관리자·일반·누락·만료·잘못된 토큰 표시, 토큰 없는 URL 전달과 실행 오류 테스트를 먼저 추가한다.
- [x] 시각 문구와 관리자 메뉴·브라우저 연결을 구현한다.

- [x] Android 화면·브라우저 연결을 가상 계정으로 확인하고 일반 APK·핫 리로드를 검증한다. 관리자 수집·변경 동작은 실행하지 않는다.
