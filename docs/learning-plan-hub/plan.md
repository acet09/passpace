# 목표·계획 통합 화면

사용자가 승인한 방향: 백엔드 전체를 유지하고 목표 설정과 계획을 학습계획 한곳에 모은다. 기존 설정만 저장하기, 계획 입력·초안·미리보기·비교·취소·명시적 저장은 유지한다.

## 화면과 이동

- 하단 학습계획 탭에 목표·기본 설정 요약, 설정 수정, 계획 만들기와 저장된 일정을 함께 배치한다.
- 설정 편집은 이 화면에서 열고 저장·취소 후 같은 화면으로 돌아온다. 저장하면 이어서 계획 만들기를 할 수 있는 안내와 버튼을 표시한다. 계획 입력은 기존 시간·이해도 불러오기를 그대로 사용한다.
- 홈의 목표·설정 버튼과 내 정보의 학습 메뉴는 학습계획 화면으로 연결한다. 명시적으로 들어올 때 요약이 보이도록 위로 이동하되 새로고침 시에는 임의 이동하지 않는다.
- 기본 설정 변경이 기존 일정을 자동 변경했다고 표시하지 않는다. 새 계획은 기존과 같이 미리보기와 저장 확인을 거쳐야 한다.
- 목표 또는 일정 조회가 실패해도 다른 영역과 가능한 동작은 사용할 수 있도록 구분한다.
- 기존 백엔드 API·요청 본문·계산·세션·데이터 모델·의존성·서버 스크립트는 수정하지 않는다. 학습량 근거·기학습 입력 등 제거된 항목도 복구하지 않는다.
