# 설정 접기와 로그인 화면 개선 계획

사용자 요청: 목표와 기본 설정을 닫을 수 있게 하고 로그인 전 화면을 자격증 학습 앱에 맞게 개선한다. 백엔드는 절대 수정하지 않는다.

## 디자인과 범위

- 기존 통합 학습계획은 유지한다. 기본 설정 제목을 48dp 이상 펼침·접힘 조작으로 만들고, 내용만 접는다. 펼침 상태는 대시보드의 화면 상태로 보관해 스크롤·탭·새로고침에 유지한다. 설정 저장 후에는 안내를 볼 수 있게 펼친다. 영구 저장은 추가하지 않는다.
- 접힌 상태에서도 기존 상단 새 계획·설정 버튼은 그대로 사용할 수 있다. 첫 진입은 펼친 상태다. 조회·저장·입력 불러오기·계산은 그대로다.
- 로그인 우선 동선과 가입 완료 후 로그인 복귀를 유지한다. 기존 블루·중립색 안에서 브랜드, 시험 준비에 맞는 짧은 소개, 목표·계획·오늘 학습 흐름, 분명한 로그인 영역으로 정돈한다.
- 소개 페이지를 별도로 거치는 방식과 대형 배너를 추가하는 방식은 피한다. 기존 첫 화면에서 로그인·가입이 바로 가능하도록 하고 서버에 없는 수치·보상·타이머·완료 데이터는 표현하지 않는다.
- 수정 파일: lib/ui/dashboard.dart(접힘 상태), plan_goal_section.dart(접힘 표현), auth.dart(레이아웃만), 새 auth_intro.dart(표현만), 관련 테스트와 검증 문서.
- API·모델·세션·저장소·의존성·환경·팀 프로젝트·다른 팀원 담당 파일은 읽기 전용이다.
