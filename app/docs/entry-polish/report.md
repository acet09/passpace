## 실제 실행

- 일반 진입점 lib/main.dart로 디버그 APK를 빌드·설치하고, 에뮬레이터에서 기존 로그인 복원 후 대시보드 진입을 확인했다. 로그아웃·계정 삭제·앱 데이터 초기화를 수행하지 않았다.
- 핫 리로드가 성공했고 전후 Dart 런타임 오류는 0건이다. 기존 Android 보안 저장소의 키 읽기 경고는 남아 있으나 대시보드가 정상 진입했다. 저장소 코드는 수정하지 않았다.
- 새 APK에 소개·접기 문구가 포함됐고 두 통합 테스트 진입점이 제외됐음을 확인했다.

## 모의 검증

- 전체 단위·화면 테스트 47개 통과. 정적 검사 오류·경고 0건.
- Android 화면 시나리오 1개 통과. MockClient와 메모리 계정·초안 저장소만 사용했다. 실제 서버 요청이나 계정·계획 쓰기는 수행하지 않았다. 이미지의 데이터는 **SAMPLE 가상 데이터**다.
- 설정 접기 기능을 구현하기 전 버튼 부재로 테스트가 실패했고 구현 후 통과했다. 30일 일정에서 설정이 화면 밖으로 제거됐다 돌아와도 접힘 상태가 유지된다.
- 키보드 검사에서 고정 MediaQuery가 키보드 높이를 가리던 문제를 검토로 발견했다. 실제 높이 280을 기대하는 검사에서 0으로 실패함을 재현했고, 화면에 전달되는 글자 확대·키보드 높이를 확인하도록 테스트를 수정했다. 6가지 조합이 통과했다.
- 회원가입으로 이동했다 돌아와도 입력이 유지된다. 저장 실패·취소·초안·미리보기·비교·명시적 저장의 기존 테스트도 통과했다.
