# 과목별 누적 원형 표시 Implementation Plan

> superpowers:executing-plans로 직접 구현하고 최종 읽기 전용 검토1회. 기존 변경 보존·커밋/배포 없음.

**Goal:** 해당 날짜 같은 과목으로 저장된 실제 분 + 이번 미저장 측정으로 원형 진행을 표시한다.
**Architecture:** 기존 날짜별 studySessions() 모든 페이지를 읽고 고유 sessionId를 집계한다. subjectId가 있으면 ID로, 없으면 실제 taskId의 시험/과목 메타데이터로 검증한다. 필요한 과거 연결 메타데이터 조회만 내부적으로 수행하고 과목 선택 UI는 ACTIVE만 유지한다. 불명확한 연결·조회 실패에는 불완전한 합계를 그리지 않는다.
**Tech Stack:** 기존 Flutter/Dart/API/패키지만 사용. 서버·DB·API·모델·측정/저장·알림·인증·초안·Android·환경 버전 변경 금지.

기존 저장 API는 분 단위다. 중심 시계는 이번 측정 그대로, 원은 저장 분+미저장 측정이다. 저장 요청/결과 불명확 동안 추가 조회를 막고 이전 표시를 유지한다. 저장 완료 상태는 미저장 측정을 합계에 다시 더하지 않는다. 날짜·선택·화면 재진입/앱 복귀·저장 상태 변화 때 갱신하고 매초 요청하지 않는다. 같은 값의 서로 다른 기록은 모두 세며 ID가 같은 페이지만 중복 제거한다.

Ruling: 현재 선택은 ACTIVE 유지. 과거 계획의 같은 과목 기록도 안정적인 과목 ID나 검증된 연결로 확인되는 경우 집계한다. 이름만 같은 다른 시험, 미연결 시간은 합치지 않는다. 과거 날짜를 복원한 타이머는 그 측정 날짜로 표시해 ‘오늘’이라고 잘못 부르지 않는다. 서버가 요청 키를 제공하지 않는 기존 응답 유실 한계는 임의 추정으로 해결하지 않는다.
