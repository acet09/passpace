## 실제 검증

- 기존 팀 Spring Boot 코드와 별도 MariaDB를 사용하는 Pixel 에뮬레이터 통합 시나리오 1개가 최종 통과했다. 가입 완료·로그인 복귀, 로그인, 목표 저장·조회, 기기 초안 복원, 입력·미리보기, 비교 상세, 저장 취소 시 기존 ID 유지, 확인 후 버전 교체, 다른 로그인에서의 재조회, 상담·후속 대화와 프로필 수정을 확인했다.
- 개선 전·후 각각 14개 화면을 촬영했다. 화면의 모바일검증 계정과 데이터는 격리된 테스트 환경의 값이다. 사용자 계정이나 기존 팀 DB에 검증용 회원·계획을 쓰지 않았다. 상담은 외부 LLM 없이 기존 Java 기본 안내를 사용했다.
- 일반 진입점 lib/main.dart로 디버그 APK를 빌드하고 에뮬레이터에 설치했다. APK 내부에서 새 화면 문구가 포함되고 제거한 입력·설명 제목과 통합 테스트 진입점이 없는 것을 확인했다. 로그인 화면 진입과 핫 리로드 성공, Dart 런타임 오류 0건을 확인했다.
- 검증용 서버·DB·임시 로그를 종료·정리했고, 기존 8080 서버가 인증 없는 회원 조회에 401로 응답하는 것을 확인했다.

## 모의·자동 검증

- 단위·화면 테스트 32개가 통과했고 flutter analyze에서 오류·경고가 없었다. HTTP 응답을 대체한 화면 검사와 실제 API 통합 검사는 구분한다.
- 개선 전 날짜 폭 40px, 긴 오류와 큰 글자의 하단 영역 초과, 오늘 과목보다 목표가 앞서는 배치를 재현했다. 개선 후 날짜 터치 영역 48dp 이상, 선택 날짜의 가로 화면 내 노출과 Android 터치 검사, 오류 상태의 다음 버튼 동작을 확인했다.
- 320px·200% 글자에서 계획 상태·버전이 가로로 37px 넘치는 문제를 재현하고 줄바꿈으로 해결했다. 같은 조건을 포함한 여섯 화면 조합이 통과했다.
- 최종 코드 검토에서 처리 중 흰색 표시와 비활성 버튼 배경의 대비 1.33:1을 재현했다. 표시를 블루로 수정하고 3:1 이상인 회귀 검사를 통과했다.
- 주요 색 조합의 계산 대비는 버튼 6.45:1, 본문 14.03:1, 보조 설명 5.94:1, 선택 표시 5.76:1, 안내 5.90:1, 성공 안내 5.74:1이었다. 입력 경계는 3.24:1이었다. 계산 기준과 색 값은 해시 검증 파일에 함께 기록했다.
- 소스 검토에서 추가 기능 회귀는 발견되지 않았다. 키보드가 남기는 공간은 작은 화면 높이로 모의했다. 이 결과가 모든 OS 키보드와 기기 조합의 실사용 검증을 의미하지는 않는다.

## 백엔드와 다른 코드 보존

- 기존 핵심 비교 범위 192개와 더 넓은 팀 프로젝트 소스·설정 203개 모두 작업 전후 추가·삭제·변경 0건이다. 203개에는 .idea의 설정도 포함한다. Git 상태도 깨끗하다.
- 앱의 데이터·세션·보안 저장소·main.dart·의존성·Android 설정·실행 스크립트 등을 포함한 보호 파일 55개가 모두 동일하다.
- 인증·가입·연결 설정·홈 상태·상담·계획 로딩·입력/초안/요청·저장의 업무 메서드 구간 8개를 공백을 제외하고 비교했으며 모두 동일하다. UI 안의 요청 본문과 계산·저장 코드를 바꾸지 않았다.
- build, .gradle, 로그 등 실행 출력은 소스 비교에서 제외한다. 검증 과정의 별도 DB 생성은 임시 폴더와 별도 포트에만 수행했다.

## 갱신 방법

Android Studio에서 기존 앱 프로젝트를 열어 다시 실행하면 된다. 실행 중인 개발 앱은 화면 갱신 또는 재시작을 사용한다. 휴대폰은 기존 Flutter 앱에 새 APK를 설치해 갱신한다. 이번 작업에서 개인 휴대폰 설치는 수행하지 않았다.

## 보류·미검증

- 보류: 서버의 날짜·시간 재배정, 45분 묶음 규칙 변경, 서버 저장의 원자적 버전 충돌 처리, 실제 공부 기록·완료율·연속 학습일, 타이머·알림 동기화. 이번에 추가하거나 화면에 있는 것처럼 표시하지 않았다.
- 미검증: 개인 휴대폰 설치와 사용자의 기존 계정, 실제 TalkBack 낭독·키보드·큰 글자 전체 조합, 외부 LLM·인터넷 서버·스토어 배포. 기존 React 웹과 루트 프로젝트의 백엔드용 Build/Postman 검사는 수정 대상과 달라 실행하지 않았고, 모바일에 맞는 위 검사로 확인했다.
