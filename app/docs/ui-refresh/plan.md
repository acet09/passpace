## 진단과 선정 방향

현재 홈은 목표 카드와 그라데이션 시간 요약이 학습 목록보다 먼저 공간을 차지한다. 로그인은 소개 배너와 환영 제목이 중복되고, 과목 행은 긴 이름과 오른쪽 시간을 좁은 Row에 함께 넣는다. 날짜 셀은 40px까지 작아질 수 있고 일부 설명은 11px다. 비교 화면의 두 합계가 같은 색으로 강조되어 이전·새 계획 구분이 약하다.

사용자가 선택한 차분한 블루 방향에 따라, 장식이 많은 대시보드나 게임형 경로 대신 오늘의 과목 중심 화면을 구현한다. 목표는 간결한 보조 행, 하루 시간은 단색의 짧은 요약, 과목은 시험·이름·시간의 계층으로 표현한다. 기존 네 탭과 모든 저장·취소·복원 동선은 유지한다.

## 검증에서 특히 볼 조건

1. 긴 시험명·과목명·장시간 표시가 큰 글자에서 서로 겹치지 않는다.
2. 작은 화면에서 오늘 과목이 주간 달력·보조 목표보다 먼저 보인다.
3. 큰 글자와 키보드에서 다음·이전·저장·오류 안내를 사용할 수 있다.
4. 초안 복원과 API 요청·비교·취소·명시적 저장은 동일하게 동작한다.
5. 빈 날짜를 휴식·완료로 추정하지 않고 계획 시간·실제 공부 시간을 혼동하지 않는다.

## 보류

실제 공부 기록·완료율·연속 학습일, 알림·타이머 동기화, 빈 날짜 재배정과 계획 계산 변경, 서버 저장의 원자적 버전 충돌 검사는 백엔드 또는 업무 동작 변경이 필요하므로 구현하지 않는다.
