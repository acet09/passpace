# 전체 일정 월간 달력

사용자가 요청한 전체 일정 달력 표현을 Flutter 앱에 적용한다. 백엔드·배정 데이터·계산·저장·인증은 그대로다.

- 이번 주 보기는 유지한다. 전체 일정은 월간 달력으로 시작하며 목록 전환으로 기존 날짜별 전체 목록도 볼 수 있다.
- 월 이동은 저장된 계획 기간 안에서 한다. 계획 기간 밖의 날짜는 선택하지 않는다. 초기 날짜는 오늘을 계획 기간 안으로 맞춘 날짜다. 월 이동 시 가능한 같은 일자를 선택한다.
- 배정 날짜는 색상 외에 배정 글자로 구별하고, 선택 날짜 아래에서 기존 과목·시험·계획 시간을 확인한다. 빈 날짜는 계획된 학습 없음으로 표시한다.
- 달력의 한 날짜는 48dp 이상이며 좁은 화면·큰 글자에서는 달력을 가로로 움직여 모든 요일에 접근할 수 있게 한다. 선택 열이 보이도록 이동하고 안내도 표시한다.
- 화면 범위: lib/ui/dashboard.dart와 새 plan_month_calendar.dart. 관련 테스트·검증 문서·APK만 추가/갱신한다. 로그인·설정 접기와 다른 화면·데이터 계층은 그대로다.
