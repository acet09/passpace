# 전체 일정 월간 달력

2026-11-15. 학습계획 → 전체 일정의 기본 보기를 월간 달력으로 바꿨다. 이번 주 보기와 기존 전체 목록은 유지한다.

- 월 이동과 오늘 선택으로 계획 기간을 살펴본다. 날짜를 누르면 아래에 해당 날짜의 과목·시험·계획 시간이 표시되고 기존 상세·상담 동작을 사용할 수 있다.
- 배정된 날짜는 배정 글자로 구별하며, 선택은 선택 글자로 표시한다. 빈 날짜는 **계획된 학습 없음**이다. 휴식·완료·실제 공부 시간으로 해석하지 않는다.
- 월별 배정일과 계획 시간은 기존 서버 배정의 합계다. 배정·시간 산정·저장 요청은 바꾸지 않았다.
- 목록 버튼으로 기존 날짜별 전체 목록을 볼 수 있다. 화면이 좁거나 글자가 크면 48dp 이상의 날짜를 좌우로 움직여 선택한다. 선택한 요일 열은 보이도록 맞춘다.
- 초기 날짜는 오늘을 계획 기간 안으로 맞춘 날짜이며, 월 이동은 가능한 같은 일자로 이동한다. 계획 밖 날짜와 월 이동은 비활성화한다.
