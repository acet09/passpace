# 화면 선택 전환 개선 Implementation Plan

> **For agentic workers:** superpowers:executing-plans로 현재 세션에서 직접 수행한다. 기존 변경 보존, 커밋/배포 없음.

**Goal:** 홈 주/월과 타이머/학습기록/통계를 동일한 선택 바에서 전환한다.
**Architecture:** 기존 상태·콜백을 그대로 사용하고 화면 상단 선택 바만 공통화한다. 기록 선택 바는 본문 스크롤 밖에 고정한다. 타이머·알림·저장·API 동작은 유지한다.
**Tech Stack:** 기존 Flutter/Dart/Material, 추가 의존성 없음.
**Spec:** 사용자의 이번 UI 전환 요청. 이전 계획 포함은 과거 기록 연결용이므로 설명하고 기능은 유지한다.
