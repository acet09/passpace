# 타이머·과목 선택·일별 통계 개선 계획

사용자 요청: 실제 타이머 추가, 날짜별 중복 과목 제거, 시간대 기술 문구 제거, 일별 수치 가독성 개선. 이전 허용 범위는 기존 학습기록 파일과 앱이며 이번 구현은 **백엔드 전체를 보존하고 앱만 변경**한다.

## 설계와 판단

- 타이머는 Flutter의 누적 측정(시작/일시정지/계속/저장)으로 만들고 기존 POST로 측정한 정수 분을 저장한다. 별도 서버 타이머·새 DB 필드·TIMER 입력 방식을 추가하는 접근은 이번 요구를 충족하는 데 불필요하므로 제외한다. 기존 API에서 수동 확인한 기록과 동일하게 수정/삭제 가능하다. 저장 전까지 서버 기록이 아니다.
- 과목은 기존 실제 항목 조회를 모두 읽고 과목 ID(없으면 자격증+과목명)로 묶는다. 다른 시험은 구분하고 ID 없는 이름도 추정하지 않는다. 내부 연결은 기존 선택 ID 우선, 그 외 현재 계획/공부 날짜와 가까운 실제 항목을 사용한다. 일정/시작 시각/공부시간을 만들지 않는다. 날짜 선택/전체 일정 UI를 제거한다.
- 타이머 상태는 기존 저장 추상화의 별도 키에 서버+계정별로 보관한다. 기존 초안/로그인 저장 키·처리는 바꾸지 않는다. 앱 전환 후 계속 측정, 일시정지는 제외한다. 날짜가 바뀌면 해당 날짜 경계에서 멈추고 저장 후 새 측정을 시작한다. 1분 미만은 저장하지 않으며 남은 초를 안내한다.
- POST 전에 저장 중 상태를 기기에 기록한다. 통신 결과 불명/저장 중 앱 종료는 재전송하지 않고 기록 목록 확인을 요구한다. 저장 성공 후 기기 상태 정리가 실패해도 새 POST를 허용하지 않는다. 계정/서버 전환 시 기존 화면을 막고 측정을 멈춘다.
- 일별 통계는 날짜·요일과 시간/분을 정렬한 행 및 비교 막대로 제공한다.7일 단위 이동으로 긴 기간도 읽을 수 있게 한다. 꺾은선/막대 그래프와 기간 선택·기존 실제 데이터/날짜 기준은 유지한다. 시간대는 내부 검증에만 남긴다.
