# PASS PACE Android

팀 웹 프로젝트 `passpace11144`의 Spring Boot API를 사용하는 Flutter/Dart 안드로이드 앱입니다. 웹과 같은 서버에 로그인하면 같은 회원 정보, 학습 목표, 저장된 계획을 읽고 수정합니다. 이 폴더만 Android Studio에서 열 수 있습니다.

## Android Studio에서 실행

1. 바탕화면의 **PASS PACE 서버 켜기** 또는 이 폴더의 **서버 켜기.cmd**를 더블클릭합니다. 이 PC의 `C:\Users\std66\passpace11144`에서 Java 21로 서버를 실행합니다. 처음 켰다면 **서버 준비 완료**가 뜬 창을 사용하는 동안 열어 두세요. 이미 켜져 있다면 안내 창은 자동으로 닫힙니다. MariaDB 시작 권한을 묻는 Windows 창이 뜨면 **예**를 누릅니다.
2. Android Studio에서 **File → Open**으로 `passpace_mobile` 폴더를 엽니다. 이 폴더에 `pubspec.yaml`이 있습니다. Flutter 및 Dart 플러그인이 필요합니다.
3. Pixel 에뮬레이터를 선택하고 **main.dart → ▶ Run**을 누릅니다. 앱의 기본 개발 서버는 `http://10.0.2.2:8080`입니다.
4. 로그인 화면에서 웹 계정의 **아이디**와 비밀번호를 입력합니다.

## 개인 휴대폰에서 사용

- **USB 개발** 기기에서 USB 디버깅과 이 PC의 연결을 허용한 뒤 **PASS PACE 서버 켜기**를 누릅니다. 실행 파일이 연결된 USB 휴대폰 한 대에 8080 포트를 연결합니다. 앱 로그인 화면 오른쪽 위에서 **USB 연결 → 연결 주소 저장**을 한 번 선택하세요. 케이블을 다시 연결했을 때도 같은 바로가기를 누르면 됩니다.
- **케이블 없이 사용** 휴대폰에서 접근 가능한 HTTPS 팀 서버를 준비하고 로그인 화면의 연결 설정에 그 주소를 저장합니다. 서버 연결이 필요한 기능은 서버와 DB가 실행 중일 때 사용할 수 있습니다.
- **APK 만들기** 이 폴더에서 `flutter build apk --debug`를 실행합니다. 결과 파일은 `build/app/outputs/flutter-apk/app-debug.apk`입니다. 배포용 기본 서버는 빌드 시 `--dart-define=PASS_PACE_API_URL=https://서비스주소`로 지정합니다. 스토어 배포 시 팀의 정식 서명 설정이 필요합니다.

- **홈** 오늘 할 과목을 먼저 표시합니다. 목록 아래 달력의 **월간**을 누르면 한 달로 확장하며 이전·다음 달도 볼 수 있습니다. 목표 시험과 계획 시간은 보조 정보로 유지합니다. 과목을 누르면 상세 정보를 확인하고 상담에 질문을 작성할 수 있습니다.
- **학습계획** 달력을 월간으로 먼저 표시하며 주간·전체 목록으로도 볼 수 있습니다. 월 제목을 누르면 계획 기간 안의 다른 날짜로 이동합니다. 새 계획은 시간과 요일, 목표 시험, 과목별 이해도의 세 단계로 입력합니다. 미리보기와 이전 단계로 돌아와도 작성한 값이 보존됩니다. 미리보기의 그래프는 실제 달력 기준 7일간의 계획 시간을 보여줍니다. 저장을 확인하면 웹에도 같은 일정이 적용됩니다.
- **기록** 누르면 집중 타이머가 바로 열립니다. 상단의 **타이머·학습기록·통계** 선택 바로 전환하며, 통계를 스크롤해도 선택 바가 같은 위치에 남습니다. 전환 중 측정값은 유지합니다.
- **상담** 기존 팀 상담 API로 질문과 후속 질문을 보냅니다. 답변 유형, 안내 및 출처를 표시하고 답변과 출처 주소를 복사할 수 있습니다.
- **내 정보** 회원정보와 전공 구분, 목표 회차 또는 직접 지정한 시험일, 하루 가용 시간과 과목 이해도를 수정합니다.

로그인 토큰은 Android 보안 저장소에 보관합니다. 로그아웃하거나 다른 서버를 선택하면 해당 기기의 토큰을 지웁니다.

## 계획 초안과 기존 값

작성한 시간·요일·시험·이해도·단계를 기기에 자동 저장합니다. 계정과 서버 주소별로 초안이 분리됩니다. 계획 만들기를 다시 열어 **이어서 작성**을 누르면 저장된 단계에서 계속할 수 있고, **새로 작성**은 해당 초안을 정리합니다. 휴대폰 뒤로가기는 이전 단계로 이동하며 첫 단계에서 나갈 때 초안을 저장합니다.

계획 입력에서는 과목 이해도만 선택합니다. 진도·누적 학습 입력과 학습량 근거·계산 기준 상세 안내를 제거했으며, 이전 버전 초안의 진도·누적 학습 값도 새 요청에는 반영하지 않습니다. 하루 시간은 기존 서버에서 사용하는 의미에 맞게 **하루 최대 학습 시간**으로 표시합니다.

저장한 기본 목표의 시간과 과목 ID가 일치하는 이해도를 먼저 채웁니다. **기존 값 불러오기**로 다시 적용할 수 있습니다. 기본 목표일은 선택한 시험에 맞는지 확인한 뒤 **저장한 목표일 사용**으로 적용합니다. 초안 저장은 활성 계획 승인과 별도로 처리하며, 계획 저장에 성공하면 해당 초안을 정리합니다.

기존 계획이 있으면 미리보기에서 현재·새 배정 시간과 추가·제외·시간 변경을 비교할 수 있습니다. **변경 상세**는 날짜·시험·과목별 시간을 보여줍니다. 저장 직전 현재 계획을 다시 조회하며, 확인하는 동안 다른 계획이 저장됐다면 비교 내용을 갱신해 재확인을 안내합니다.

## 학습기록 관리와 추가 API 목록

기록 목록의 **수정**에서 직접 입력한 기록의 날짜·공부시간·연결 과목을 바꿀 수 있습니다. **삭제**는 확인창에서 확정하며, 취소하면 기록을 유지합니다. 저장·삭제 후 목록과 개인 통계를 서버에서 다시 조회합니다.

추가·수정 화면의 **과목 연결 · 선택**에서 현재 학습계획의 과목을 고릅니다. 날짜별로 반복되는 같은 과목은 한 번만 표시하며 다른 자격증의 과목은 구분합니다. **이전 계획 포함** 옵션은 제거했습니다. 과목 연결은 선택 사항이며 입력한 공부시간을 계획 시간으로 덮어쓰지 않습니다. 과거에 저장한 기록의 연결은 자동으로 변경하지 않습니다.

**기록**을 누르면 집중 타이머가 바로 열립니다. 시작·일시정지·계속 측정 후 **기록 저장**을 누릅니다. 측정한 정수 분을 기존 학습기록 API로 저장하며, 이후 날짜·시간 수정과 삭제가 가능합니다.1분 미만은 저장하지 않고 남은 초는 화면에서 안내합니다. 앱을 이동해도 측정하며, 날짜가 바뀌면 그날의 측정을 멈춥니다. 기기에 서버·계정별 상태를 보관해 다시 열 때 복원합니다.

선택 과목의 해당 날짜 배정 시간을 큰 원으로 표시합니다. **그날 같은 과목으로 저장된 시간 + 이번 미저장 측정**을 합산해 원을 채웁니다. 예를 들어 배정30분에 저장15분·이번5분이면 누적20분을 표시합니다. 저장 후에는 같은 타이머 화면에서 선택 과목과 저장된 누적 시간을 유지하고, 이번 시계만0으로 돌아갑니다. **측정 시작**을 누르면 과목을 다시 고르지 않고 이어서 측정합니다. 자동으로 측정을 시작하지 않으며, 직접 **측정 초기화**하면 과목 선택도 초기화됩니다. 중앙 시계는 이번 측정이며 저장할 시간도 이번 측정분만 사용합니다. 배정 시간에 도달해도 측정은 계속되고, 배정이 없거나 조회에 실패하면 임의의 목표나 부분 합계를 표시하지 않습니다.

측정 중에는 Android 알림창에서 과목과 경과 시간을 확인할 수 있습니다. 처음 요청하는 알림 권한을 허용하세요. 거부해도 앱의 측정은 계속되며 안내의 **알림 설정**에서 변경할 수 있습니다. 알림을 누르면 타이머로 돌아옵니다. 입력 화면을 열어둔 경우 입력을 보존한 채 타이머를 그 위에 표시합니다. 일시정지·저장·초기화·로그아웃하면 진행 알림을 종료합니다.

저장 결과가 불확실하면 자동 재전송하지 않습니다. 기록 목록을 확인한 뒤 **저장된 기록 확인**으로 측정을 마치거나 **기록 없음 · 측정 유지**로 측정값을 보관합니다. 다시 저장할 때는 중복 기록이 없는지 먼저 확인합니다.

**개인 통계**는 기존 기간·꺾은선/막대 그래프를 유지하며 날짜·요일·시간/분으로 일별 공부시간을 보여줍니다. 긴 기간도7일씩 이동해 확인할 수 있습니다. 데이터의 날짜 기준과 API 계약은 그대로이며 화면의 시간대 기술 문구만 제거했습니다.

[타이머·과목·통계 개선 검증과 화면](docs/study-timer/verification.md). 이 개선은 앱만 변경했으며 서버 API·DB·다른 팀원 코드·패키지 버전은 유지했습니다.
